# Booking



Веб-приложение для управления бронированием столиков в ресторане. Система позволяет вести справочник гостей и столиков, создавать и редактировать брони, искать свободные столы на выбранный временной интервал и предотвращает конфликты при пересечении броней на одном столике.



Проект состоит из REST API на ASP.NET Core и одностраничного клиента на React. Бэкенд организован по слоям: API-контроллеры, бизнес-логика, репозитории и общие модели. Данные хранятся в JSON-файлах на диске; при первом запуске каталог и файлы создаются автоматически.



## Архитектура



Решение разделено на четыре проекта:



\- Booking — точка входа, контроллеры, DTO, маппинг AutoMapper, централизованная обработка ошибок, настройка CORS и DI.

\- Booking.BLL — сервисы с бизнес-правилами: проверка уникальности телефона гостя и номера столика, контроль пересечения интервалов бронирования, поиск доступных столов.

\- Booking.DAL — репозитории с чтением и записью JSON; доступ к файлам синхронизируется через `SemaphoreSlim`.

\- Booking.Shared — доменные модели (`Guest`, `Table`, `Reservation`) и интерфейсы сервисов и репозиториев.



Клиент (`booking.ui`) обращается к API через axios. Маршрутизация построена на React Router: три раздела — бронирования, столики и гости. Для каждой сущности реализованы список, окна создания и редактирования, боковая панель фильтров. На странице бронирований фильтр по времени показывает свободные столики; выбор создания брони открывает соответствующую форму с предзаполненными полями.



Ошибки доменного уровня (`NotFoundException`, `ConflictException`) перехватываются в API и возвращаются клиенту в виде JSON с соответствующими HTTP-кодами.



## Стек



Backend: .NET 9, ASP.NET Core Web API, AutoMapper  

Frontend: React 19, React Router 7, axios  

Хранение данных: JSON-файлы (`Data/bookings.json`, `Data/guests.json`, `Data/tables.json`)
